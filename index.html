나의 편집 공간

이 브라우저에서 한 수정은 아직 공개되지 않습니다.

다른 사람에게 변경 내용을 보여주려면 아래에서 data.js 다운로드 후 GitHub 저장소의 같은 파일을 교체하세요. 방문자는 내용을 볼 수 있지만 공개 파일은 수정할 수 없습니다.

과목 관리

과목을 삭제하면 해당 과목의 기존 자료는 '기타' 과목으로 이동합니다.

공개 방법

  1. 사이트 파일을 GitHub 공개 저장소에 올립니다.
  2. Settings → Pages에서 Deploy from a branch, main, /(root)를 선택합니다.
  3. 사이트에 새 글을 작성한 후 data.js 다운로드를 눌러, 저장소의 data.js 파일을 교체하고 커밋합니다.
  4. 배포된 주소를 친구들에게 공유합니다.

※ 이 편집 모드는 개인 브라우저 작업 공간입니다. 비밀번호가 있는 관리자 서버 기능은 제공하지 않습니다.
