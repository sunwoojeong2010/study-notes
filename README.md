# NoteSpace — 수업 필기 · 문제풀이 공유 사이트

수업 필기와 문제풀이를 **과목별로 정리해서 누구나 링크로 읽을 수 있게** 만드는 정적 웹사이트입니다. 별도 서버나 코딩 지식 없이 GitHub Pages에 게시할 수 있습니다.

## 1. 바로 확인하기

압축을 풀고 `index.html`을 더블클릭해 열어 보세요. 수학, 물리, 화학, 프로그래밍에 대한 **예시 콘텐츠**가 들어 있습니다. 모든 파일을 같은 폴더에 두세요.

- 과목별 분류 / 수업 필기·문제 풀이 구분
- 제목·본문·태그 검색
- 문제 해설 펼치기, 즐겨찾기, 개별 글 링크
- 모바일 화면, 다크 모드, 인쇄
- 마크다운과 LaTeX 수식 (`$...$`, `$$...$$`) 지원
- 브라우저에서 추가·수정·삭제 / `data.js`로 저장·불러오기

**주의:** 웹 글꼴, 수식 및 Markdown 처리는 CDN을 사용하므로 인터넷 연결이 있을 때 가장 완전하게 표시됩니다. 기본 사이트는 네트워크 없이도 열립니다.

## 2. 다른 사람도 링크로 보게 공개하기 (무료 GitHub Pages)

1. [github.com](https://github.com/)에서 계정을 만들거나 로그인합니다.
2. 오른쪽 위 `+` → **New repository**를 선택합니다.
3. 저장소 이름을 `study-notes`로 지정하고 **Public**으로 만든 뒤 저장소를 생성합니다.
4. **Add file → Upload files**를 선택해 이 폴더의 다음 파일을 루트에 올립니다.
   - `index.html`
   - `styles.css`
   - `app.js`
   - `data.js`
   - `.nojekyll` (숨김 파일이 안 보이면 생략해도 기본 사이트는 동작합니다.)
5. **Commit changes**를 누릅니다.
6. 저장소 **Settings → Pages → Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
7. **Branch: main / Folder: /(root)**를 선택하고 **Save**합니다.
8. 공개된 주소는 일반적으로 `https://깃허브아이디.github.io/study-notes/` 형식입니다. Pages 설정의 **Visit site**에서 확인하세요.
9. 그 주소를 공유하면 다른 사람은 로그인 없이 자료를 볼 수 있습니다.

GitHub Free에서 GitHub Pages는 **공개 저장소**를 사용합니다. 따라서 공개하고 싶지 않은 이름, 연락처, 개인 정보, 과제 답안 등은 업로드하지 마세요.

## 3. 새 필기나 문제 추가하기

1. 사이트 상단 **＋ 새 자료 작성**을 누릅니다.
2. 과목, 제목, 내용, 태그를 입력하고 저장합니다. 문제풀이를 선택하면 별도 해설도 작성할 수 있습니다.
3. 왼쪽 아래 **편집 · 게시 관리**를 누릅니다.
4. **data.js 다운로드**를 누릅니다.
5. GitHub 저장소에서 기존 `data.js`를 새 파일의 내용으로 교체한 후 **Commit changes**를 누릅니다. 예: 파일 목록에서 `data.js` 선택 → 연필 아이콘 (Edit) → 파일 전체 내용을 새로 내려받은 `data.js`의 내용으로 교체 → Commit. 또는 저장소에서 기존 파일을 삭제하고 새 파일을 업로드해도 됩니다.
6. GitHub Pages 업데이트 후 방문자가 새 내용을 볼 수 있습니다.

**중요한 구조:** 사이트 안에서 수정한 내용은 **현재 브라우저의 localStorage**에만 자동 저장됩니다. `data.js` 다운로드와 GitHub 업로드까지 해야 공개됩니다. 친구들이 편집 버튼을 누르더라도 공개 파일을 수정할 수는 없고 자기 브라우저에만 기록됩니다. 이는 비밀번호를 가진 관리자 기능이 아닙니다.

다른 기기에서 편집하려면 최신 `data.js`를 그 기기의 사이트에 **편집 공간 → data.js 불러오기**로 먼저 가져오세요. GitHub에 새 글을 공개한 뒤 기존 브라우저에 옛 데이터가 계속 보이면 **공개본으로 되돌리기**를 사용하세요. 이 작업은 브라우저에 아직 게시하지 않은 수정 내용을 지우므로 파일로 먼저 백업하세요.

## 4. 콘텐츠 작성 형식

- `# 큰 제목`, `## 소제목`, `**강조**`, `- 목록`, `1. 번호`, `` `코드` ``
- 인라인 수식: `$E=mc^2$`
- 가운데 수식: `$$\\frac{a}{b}$$` (편집기에서 실제로는 백슬래시 1개 `\frac` 사용)
- 코드 블록: 백틱 세 개로 시작하고 `c`, `python` 등의 언어 이름을 추가할 수 있습니다.
- 이미지: `![설명](https://이미지주소)` — 인터넷에 공개된 이미지 URL을 사용하세요. 이미지는 자동 업로드되지 않습니다.
- PDF: `[PDF 보러가기](https://자료주소)`

## 5. 전체 파일 구조

```
study-archive-site/
├── index.html    # 사이트 화면
├── styles.css    # 디자인 (반응형, 다크 모드)
├── app.js        # 탐색, 검색, 글 열기, 편집, 내보내기
├── data.js       # 공개되는 과목 및 자료 데이터
├── .nojekyll     # GitHub Pages 배포 설정
└── README.md     # 사용법
```

## 6. 유의사항

- 이 웹사이트는 **정적**입니다. 공개 읽기와 로컬 편집은 가능하지만, 글을 추가하자마자 자동으로 모든 방문자에게 반영되는 실시간 공동 편집 서비스는 아닙니다. 그 기능이 필요하다면 별도의 데이터베이스와 로그인 시스템을 추가해야 합니다.
- GitHub Pages는 공개 웹사이트입니다. 링크를 모르는 사람도 검색 또는 다른 경로로 접근할 수 있습니다. **링크 소유자에게만 접근을 제한하는 사이트가 아닙니다.**
- 새 파일 `data.js`를 게시하기 전에는 원본 파일의 사본을 보관하는 것을 권장합니다.
- 각 글의 고유 주소는 `https://.../#note=글ID` 형식이며 페이지에 공개된 자료를 가리킵니다.
- GitHub 공식 도움말: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
